# Privacy policies

Privacy policies for browser extensions by Nik Kale.

- [Elk New Tab](ELK-NEW-TAB-PRIVACY.md)
- [Nanotations](NANOTATIONS-PRIVACY.md)

This repository contains public privacy documents. Extension source code is maintained separately.

For privacy questions, open an issue and include the extension name. Do not include private page content, credentials, or exported annotation data.
